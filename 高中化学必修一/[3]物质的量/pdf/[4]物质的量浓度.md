# 2. 物质的量浓度

<table><thead><tr><th>定义</th><th>表示单位体积的溶液里所含溶质 B 的物质的量</th></tr></thead><tbody><tr><td>对象</td><td>混合气体或溶液</td></tr><tr><td>符号</td><td>$C_B$</td></tr><tr><td>单位</td><td>常用单位是“$mol\cdot L^{-1}$”或“mol/L”</td></tr><tr><td>公式</td><td>$C_B = \frac{n_B}{V}$</td></tr><tr><td>规律</td><td>溶液一旦配制好，浓度就为定值，与所取用的溶液体积无关。</td></tr></tbody></table>

注：(1)公式中的 V 是溶液体积，不是溶剂(水)的体积。
(2)溶液中溶质往往不单一，一定要指明浓度的研究对象。
(3)溶液稀释公式：$n_{B浓} = n_{B稀} \rightarrow c_{B浓} V_{浓} = c_{B稀} V_{稀}$

# 3. 质量分数与物质的量浓度的关系

$c_B = \frac{n_B}{V}$

$n_B = \frac{m_B}{M_B}$

$c_B = \frac{m_B}{M_B}$

$c_B = 1000 \times \frac{m_B}{M_B} \times \frac{\rho}{m_{溶液}}$

$c_B = \frac{1000 \rho \omega_B}{M_B}$

ρ的单位一般为g/mL，因此溶液体积为mL，则$\frac{m_{溶液}}{\rho} \times 10^{-3}$单位为L。

(ρ、ωB、MB分别表示溶液密度、溶质B的质量分数、溶质B的摩尔质量，且ρ的单位是g/mL)

# 实验室配制一定物质的量浓度的溶液

## 配制100 mL 1.00 mol/L $\text{Na}\text{Cl}$溶液

### (1) 计算需要$\text{Na}\text{Cl}$固体的质量：

$m(\text{NaCl}) = C \times V \times M = 1.00 \, \text{mol/L} \times 0.1 \, \text{L} \times 58.44 \, \text{g/mol} = 5.844 \, \text{g}$

### (2) 称量$\text{Na}\text{Cl}$固体：

称取5.844 g $\text{Na}\text{Cl}$固体。

### (3) 将称好的$\text{Na}\text{Cl}$固体放入烧杯中，加入适量蒸馏水，用玻璃棒搅拌，使$\text{Na}\text{Cl}$固体全部溶解。

### (4) 将烧杯中的溶液沿玻璃棒注入100 mL容量瓶(如图2-25)，并用少量蒸馏水洗涤烧杯内壁和玻璃棒2-3次，将洗涤液也注入容量瓶。轻轻摇动容量瓶，使溶液混合均匀。

### (5) 将蒸馏水注入容量瓶，当液面离容量瓶颈部的刻度线1-2 cm时，改用胶头滴管滴加蒸馏水至溶液的凹液面与刻度线相切。盖好瓶塞，反复上下颠倒，摇匀。

### (6) 将配制好的溶液倒入试剂瓶中，并贴好标签。
