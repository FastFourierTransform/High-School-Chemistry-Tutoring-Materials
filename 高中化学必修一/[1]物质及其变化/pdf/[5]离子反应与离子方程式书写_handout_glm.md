## [1-5]离子反应与离子方程式书写

#### 1. 离子反应
有离子参加或生成的反应。
#### 2. 离子方程式
用实际参加反应的离子符号来表示反应的式子。

注：“电离方程式”表示电离(物理变化)过程；“离子方程式”表示化学反应过程。
#### 3. 离子方程式的书写步骤

<table>
 <tr>
 <th>步骤</th>
 <td>意义及实例(以 $\text{Ag}\text{N}\text{O}_3$ 与 $\text{Na}\text{Cl}$ 反应为例)</td>
 </tr>
 <tr>
 <th>写</th>
 <td>写出反应的化学方程式：$AgNO_3 + NaCl = AgCl \downarrow + NaNO_3$</td>
 </tr>
 <tr>
 <th>拆</th>
 <td>把易溶于水且易电离的物质(如强酸、强碱和大部分可溶性盐)写成离子形式，难溶的物质、气体和水等仍用化学式表示。上述化学方程式可改写成：$Ag^+ + NO_3^- + Na^+ + Cl^- = AgCl \downarrow + Na^+ + NO_3^-$</td>
 </tr>
 <tr>
 <th>删</th>
 <td>删去方程式两边不参加反应的离子，并将方程式化为最简：$Ag^+ + Cl^- = AgCl \downarrow$</td>
 </tr>
 <tr>
 <th>查</th>
 <td>检查离子方程式两边各元素的原子个数和电荷总数是否相等</td>
 </tr>
</table>

注：(1)在水溶液中，完全以自由移动的离子形式存在的物质才能“拆”成离子的形式。
(2)强酸中“浓硫酸”不拆，因为其体系中的水很少，而 $\text{H}_2\text{S}\text{O}_4$ 分子要依赖水才能电离。浓硫酸体系中的 $\text{H}_2\text{S}\text{O}_4$ 未完全电离，所以不拆。
(3)强碱 $\text{Ca}(\text{O}\text{H})_2$ 是微溶性物质，微溶物作为产物一律不拆；作为反应物，“浑浊”不拆，“澄清”则拆。
(4)易溶的强电解质盐，若作为产物以沉淀的形式析出，则不拆。如侯氏制碱法反应中：$\text{Na}\text{Cl} + \text{H}_2\text{O} + \text{N}\text{H}_3 + \text{C}\text{O}_2 = \text{N}\text{H}_4\text{Cl} + \text{Na}\text{H}\text{C}\text{O}_3\downarrow$，其离子方程式为 $\text{Na}^+ + \text{H}_2\text{O} + \text{N}\text{H}_3 + \text{C}\text{O}_2 = \text{N}\text{H}_4^+ + \text{Na}\text{H}\text{C}\text{O}_3\downarrow$。
(5)氧化物一律不拆。

#### 4. 离子方程式的意义
离子方程式不仅可以表示某个具体的化学反应，还可以表示同一类型的离子反应。

#### 5. 复分解型离子反应发生的条件
##### (1) 溶解度大制溶解度小
例：$\text{CaCl}_2$溶液与$\text{NaOH}$溶液反应：$\text{Ca}^{2+} + 2\text{OH}^{-} = \text{Ca(OH)}_2\downarrow$。
##### (2) 难挥发（沸点高）制易挥发（沸点低）
例：稀硫酸与$\text{Na}_2\text{CO}_3$溶液反应：$2\text{H}^{+} + \text{CO}_3^{2-} = \text{CO}_2\uparrow + \text{H}_2\text{O}$
##### (3) 强电解质制弱电解质
例：醋酸钠与盐酸反应：$\text{CH}_3\text{COO}^{-} + \text{H}^{+} = \text{CH}_3\text{COOH}$。

注：上述三个条件“满足其一即可”，部分反应甚至可能违背上述规律。
如反应：$\text{H}_2\text{S} + \text{CuSO}_4 = \text{CuS}\downarrow + \text{H}_2\text{SO}_4$违背了“强酸制弱酸”，但遵循“溶解度大制溶解度小”，故该反应可以进行。
