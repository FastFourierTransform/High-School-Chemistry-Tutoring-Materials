## [1-11]氧化还原方程式的配平

### 配平方法的分类
#### 1. 配平的关键
配平氧化还原反应是定量过程，解决定量过程的关键是抓住“单一变量”，意思就是配平的时候一般解决化合价单纯升高，或化合价单纯降低的元素。
#### 2. 反应类型与配平方法的选择

注：①“正向配平”指的是先确定反应物的化合价，再确定产物的化合价，即从前往后配平；“逆向配平”指的是先确定产物的化合价，再确定反应物的化合价，即从后往前配平。
②方程式的单一变量在哪里，就从哪里开始分析。由于部分氧化还原反应和歧化反应的单一变量在产物，所以这类反应一般用“逆向配平”法。
③方法并非一成不变，具体问题具体分析，要灵活的使用两种方法，有时候甚至用“正逆夹击”法，即一种元素从反应物开始分析，一种元素从产物开始分析。

 </tr>
 <tr>
 <td>实例</td>
 <td>$\_\_ \overset{-3\quad}{\underset{\uparrow 5\quad}{\text{NH}_3}} + \_\_ \overset{0\;\;}{\underset{\downarrow 2 \times 2}{\text{O}_2}} \overset{催化剂}{\underset{\triangle}{\longrightarrow}} \_\_ \overset{+2-2}{\text{NO}} + \_\_ \overset{\quad-2}{\text{H}_2\text{O}}$
</td>
 </tr>
 </tbody>
 <tr>
 <td rowspan=2>找倍数</td>
 <td>解释</td>
 <td>找出化合价升降的“最小公倍数”，若不是最小公倍数，会导致化学方程式的化学计量数不是最简比</td>
 </tr>
 <tr>
 <td>实例</td>
 <td>$\_\_\underset{\uparrow 5 \times 4\quad}{\text{NH}_3} + \_\_\underset{\downarrow 4\times 5}{\text{O}_2} \overset{\text{催化剂}}{\underset{\triangle}{\longrightarrow}} \_\_\text{NO} + \_\_\text{H}_2\text{O}$</td>
 </tr>
 <tr>
 <td rowspan=2>定化学计量数</td>
 <td>解释</td>
 <td>将前面步骤中，扩大的倍数作为分析对象的化学计量数</td>
 </tr>
 <tr>
 <td>实例</td>
 <td>$4\underset{\uparrow 5 \times 4\quad}{\text{NH}_3} + 5\underset{\downarrow 4\times 5}{\text{O}_2} \longrightarrow \_\_\text{NO} + \_\_\text{H}_2\text{O}$</td>
 </tr>
 <tr>
 <td rowspan=2>用守恒</td>
 <td>解释</td>
 <td>根据原子守恒配平其他物质（一般先配“四样”，即“氧氧还还”)<br>根据变价元素 N、O 守恒配平 $\text{N}\text{O}$ 和 $\text{H}_2\text{O}$：</td>
 </tr>
 <tr>
 <td>实例</td>
 <td>$4\text{NH}_3 + 5\text{O}_2 \overset{\text{催化剂}}{\underset{\triangle}{\longrightarrow}} 4\text{NO} + 6\text{H}_2\text{O}$</td>
 </tr>
 <tr>
 <td rowspan=2>查守恒</td>
 <td>解释</td>
 <td>检查剩余原子是否守恒，并将“$\longrightarrow$”改为“$=$”；若为“有机反应”则直接用“$\longrightarrow$”</td>
 </tr>
 <tr>
 <td>实例</td>
 <td>本题可检查 H 原子是否守恒，完成化学方程式的配平：<br>$4\text{NH}_3 + 5\text{O}_2 \overset{\text{催化剂}}{\underset{\triangle}{=}} 4\text{NO} + 6\text{H}_2\text{O}$</td>
 </tr>
</table>

配平下列化学方程式：

(1) $\underline{\quad}\text{NO}_2 + \underline{\quad}\text{H}_2\text{O} \rightarrow \underline{\quad}\text{NO} + \underline{\quad}\text{HNO}_3$

(2) $\underline{\quad}\text{NaN}_3 + \underline{\quad}\text{KNO}_3 \rightarrow \underline{\quad}\text{N}_2 \uparrow + \underline{\quad}\text{Na}_2\text{O} + \underline{\quad}\text{K}_2\text{O}$

(3) $\underline{\quad}\text{Fe}_3\text{O}_4 + \underline{\quad}\text{HNO}_3 \rightarrow \underline{\quad}\text{NO} \uparrow + \underline{\quad}\text{Fe(NO}_3\text{)}_3 + \underline{\quad}\text{H}_2\text{O}$

(4) $\underline{\quad}\text{K}_2\text{Cr}_2\text{O}_7 + \underline{\quad}{\text{C}}_2\text{H}_6\text{O} + \underline{\quad}{\text{H}}_2\text{SO}_4 \rightarrow \underline{\quad}{\text{Cr}}_2(\text{SO}_4)_3 + \underline{\quad}{\text{C}}_2\text{H}_4\text{O}_2 + \underline{\quad}{\text{K}}_2\text{SO}_4 + \underline{\quad}{\text{H}}_2\text{O}$

(5) $\underline{\quad}{\text{FeS}}_2 + \underline{\quad}{\text{O}}_2 \rightarrow \underline{\quad}{\text{SO}}_2 + \underline{\quad}{\text{Fe}}_2\text{O}_3$

(1)酸性条件下：$\_\_\text{Cr}_2\text{O}_7^{2-} + \_\_\text{Fe}^{2+} + \_\_ \rightarrow \_\_\text{Cr}^{3+} + \_\_\text{Fe}^{3+} + \_\_$

(2)强碱溶液中：$\_\_\text{Fe(OH)}_3 + \_\_\text{ClO}^- + \_\_ \rightarrow \_\_\text{FeO}_4^{2-} + \_\_\text{Cl}^- + \_\_$

(3)水溶液中：$\_\_\text{SO}_2 + \_\_\text{ClO}^- + \_\_ \rightarrow \_\_\text{SO}_4^{2-} + \_\_\text{Cl}^- + \_\_$

注：①酸性条件下，在左侧或右侧补$\text{H}^+$;
②碱性条件下，在左侧或右侧补$\text{OH}^-$;
③中性条件下（水溶液中），只能在右侧补$\text{H}^+$或$\text{OH}^-$；
④$\text{H}^+$，$\text{OH}^-$和$\text{H}_2\text{O}$不是一定要补的，要根据电荷守恒和原子守恒具体问题具体分析。
